Scratch Cat FX install, remove and use (works fully offline)
=====================================================

Windows
  Run windows\ScratchCatFx-Setup.exe. It installs two things: the VST3 plugin for your DAW
  (C:\Program Files\Common Files\VST3, fixed location, all users) and the standalone app plus manual
  (C:\Program Files\Studio 87\Scratch Cat FX, the folder the installer asks about).
  Windows may show a blue "unknown publisher" screen because the installer is not signed:
  click "More info", then "Run anyway".
  Remove: Settings > Apps > Scratch Cat FX > Uninstall. It asks if you also want your saved presets deleted
  (default is No, so they stay).

macOS
  Open macos\ScratchCatFx-macOS.pkg. It installs the VST3 plugin, the standalone app, the manual and "Uninstall Scratch Cat FX".
  The installer is not notarized: if macOS blocks it, open System Settings > Privacy & Security and choose "Open Anyway".
  Remove: open "Uninstall Scratch Cat FX" in the Applications folder. It asks if you also want your saved presets deleted
  (default is Keep).

Linux, DAW installed as a Flatpak (for example Bitwig, Reaper or Ardour from Flathub)
  1. Your DAW should use the org.freedesktop.Platform 25.08 runtime (check with: flatpak info <DAW id>, Runtime line).
  2. Install the file from the linux folder:
       flatpak install --user linux/ScratchCatFx-flatpak-25.08.flatpak
  3. Restart the DAW and rescan plugins.
  Remove: flatpak uninstall --user org.freedesktop.LinuxAudio.Plugins.ScratchCatFx   (removes the plugin completely)

Linux, DAW installed natively
  Extract linux/ScratchCatFx-linux-vst3.tar.gz into ~/.vst3  (create the folder if needed), then rescan plugins.
  Remove: delete the "Scratch Cat FX.vst3" folder from ~/.vst3.

Your saved presets (kept on remove unless you choose to delete them)
  Windows : %APPDATA%\Studio 87\ScratchCatFx\presets
  macOS   : ~/Library/Application Support/Studio 87/ScratchCatFx/presets
  Linux   : ~/.config/Studio 87/ScratchCatFx/presets  (a Flatpak DAW keeps its own copy under ~/.var/app/<DAW id>/config/)
  To delete them yourself, remove the Studio 87/ScratchCatFx folder at that place.

Manual: ScratchCatFx-manual.pdf (every control plus recommendations).
Checksums: SHA256SUMS.
